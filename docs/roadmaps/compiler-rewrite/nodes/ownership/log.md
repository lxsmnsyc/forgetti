- Start: brief verify finds no test folder; `analyzeOwnership` is the `contracts` stub. Nothing exists yet, so the whole node is to do.

- Freshness is a fixed point: the walk runs with a fresh set, marks every binding that receives a fresh value, and repeats until the set stops growing. Union-find then runs only over fresh bindings, so a call result stored in an object does not become a member.
- Inputs are computed after grouping, from source ranges: every reference inside a group's stores, mutations, created literals and the conditions of its mutations. Locals declared inside the group's span (loop variables) and call-free consts are traced to what they read. Hook and call results stay inputs.
- Conditions: `alias_branch` showed that `flag` must be an input. A condition counts only when its arm does not hold the group's first literal.
- Escape rule: a group with a closure bails when some escape (JSX prop or child, return, hook or unknown call argument) ends before the group's last mutation, loop-extended. An unknown call that is itself the last mutation does not bail.
- Rebinding a member (`y = x`, `el = <A/>` in each switch case) is recorded as a mutation. Safe, but `base/switch` gets three mutations for `el`. The `branches` planner may want to treat first writes differently.
- Open doubt: debate says a spread copy starts a new group. Nested objects shared by the copy and the source are not joined, so `b = [...a]; b[0].x = 1` changes `a`'s element without a mutation on `a`. Followed the debate; not seen in the corpus.
- Open doubt: a closure that mutates a cached group and escapes after the freeze point (an event handler) is allowed, as the debate says. A later render that hits the cache then sees the handler's change. React Compiler treats this as a rules violation too.
- Base and tuning corpus: no unit bails with `escaping-closure`. `base/bailout` lists `ref` as opaque (`ref.current = ...`).
