Meaning of codes
outer_binding_unstable: JSX/value reads a binding declared outside the unit that isStableOuter rejects (imported components, module values).
cand_result_not_readonly: const x = call(...) where x is later handed on or changed (isResultReadOnly false). Includes hook calls.
cand_destructuring: const { a, ...rest } = expr; not a plain-name declarator.
cheap_expression: value cheaper than one compare, no slot by design.
impure_syntax: isPureSyntax false (calls, new, hooks, assignments inside the node).
cand_result_unsafe: the result binding is in ctx.unsafe (a group changes it or it changes in render).
unstable_global_read/write: a global outside STABLE_GLOBALS read or written in the node.

Caveats
- Sites are not weighted by steps lost. A refusal counts once whether it costs 0 or many cache hits.
- cheap_expression is a deliberate no-slot choice; destructuring and hook-call results (many cand_result_not_readonly rows are hook calls) are not cacheable by any compiler, so they may not map to lost hits.
- Nested pieces each log their own refusal, so one JSX tree can add several outer_binding_unstable rows.
- Not in the tally: units that next skips or bails out (diagnostics), and refusals in loops.ts/branches.ts/baseline.ts.
