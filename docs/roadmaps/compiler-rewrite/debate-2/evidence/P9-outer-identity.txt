2. packages/forgetti/src/next/plan/baseline.ts
   - isStableOuter (323-346): a `const X = forwardRef(...)`/`memo(...)` binding is stable only through
     isComponentWrapper (352-364), which returns false when any reference has a MemberExpression parent.
     `X.displayName = 'X'` at module top level is such a reference, so every element `<X/>` is refused.
   - a function binding is stable only when readsChangingState (268-320) is false. It walks the whole
     function, deferred closures included, and returns true on any non-STABLE_GLOBALS global
     (document, window, globalThis) or any `.current` / `.random` / `.now` member (IMPURE_MEMBERS, line 62).
     So a function component that reads `ref.current` in an effect, or `document` in a handler, is
     refused as a JSX tag, although `<X/>` never calls X during the parent's render.
3. packages/forgetti/src/next/plan/groups.ts 736-740: getBindingDeps returns undefined (refuse) for every
